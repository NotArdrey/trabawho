# Moderation

`/admin/moderation` covers reports, flagged content, and moderation cases.

- Review context must show the reporter, target, reason, evidence, and current case state when available.
- Removal actions name the affected content and require confirmation.
- Successful actions update or refetch the authoritative list; failures preserve the item and provide corrective feedback.
- Status is conveyed with text and icons as well as color.
