# Admin Dashboard

The `/admin` dashboard is an operational overview. It must prioritize current workload, risks, and clear routes into focused management areas.

## Required sections

- Verified overview metrics for users, service providers, active accounts, and review workload.
- Pending review summaries that link to the responsible management area.
- Recent activity derived from available account, moderation, or audit records.
- Honest system-status indicators for each connected data source.
- Quick actions for frequent administrative tasks.
- Recent sensitive admin actions when an audit source is available.

The dashboard must represent loading, empty, partial, and recoverable-error states without replacing missing values with sample production data.
